# Gimnasios personales de BioDex

Liga de los cinco sellos para los cursos de Nicolás Espinoza. Este proyecto se mantiene separado de la BioDex distribuida como gestor.

La conexión consulta las cuentas y bioformas del servicio actual de BioDex. Las preguntas, líderes, reglas de combate y recompensas se administran en este repositorio.
