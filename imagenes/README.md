# Imágenes de preguntas

Guarda aquí las ilustraciones de las preguntas usando PNG, WEBP, JPG o SVG.
En la pregunta JSON añade:

```json
"figure": {"src": "imagenes/neurona-01.png", "alt": "Esquema de una neurona con sus partes numeradas"}
```

Usa nombres sin espacios y proporciona un texto alternativo que describa la información necesaria sin revelar la respuesta. El tiempo se controla mediante `seconds` en esa misma pregunta.
