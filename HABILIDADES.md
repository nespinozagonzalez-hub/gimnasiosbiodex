## Afinidades

Ventaja ×1,25; si la relación está invertida, resistencia ×0,85; el resto ×1. Se aplica a ambos bandos. Cada familia tiene dos ventajas y dos resistencias.

| Tipo atacante | Ventaja frente a |
|---|---|
| Aurora | Umbral, Bruma |
| Prisma | Aurora, Nova |
| Nexo | Prisma, Vector |
| Nova | Nexo, Arcana |
| Bruma | Nova, Terra |
| Lumen | Bruma, Umbral |
| Vector | Lumen, Prisma |
| Umbral | Vector, Terra |
| Arcana | Aurora, Lumen |
| Terra | Arcana, Nexo |

Astral usa las afinidades de Prisma; Abisal, las de Umbral; Primordial, las de Arcana. Las mega legendarias solo se habilitan en una cuenta real si aparecen en sus capturas. El ensayo permite probarlas prestadas.
